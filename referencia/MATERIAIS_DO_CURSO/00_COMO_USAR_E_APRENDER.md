# Como usar os prompts e aprender a escrever

## A ideia principal
O aluno não precisa saber escrever um prompt avançado: ele pode informar só o **tema**. Mas a aula não deve ensinar a aceitar automaticamente a primeira resposta: deve explicar a técnica por trás das escolhas e incentivar a **reescrita humana**.

## Caminho rápido
- Copie o prompt 08 se quiser começar com um roteiro completo a partir de um tema.
- Copie o prompt 02 para treinar especificamente ganchos.
- Copie o prompt 09 para revisar criticamente o roteiro.

## Caminho para aprender de verdade
1. Faça uma ideia inicial à mão em uma frase.
2. Use os prompts 01–07 para entender cada mecanismo da história; não precisa usar todos sempre.
3. Use o 08 para redigir ou organizar o roteiro.
4. Use o 09 para descobrir problemas — não aceite críticas vagas.
5. Use o 10 para reescrever; preserve as partes que funcionam.
6. Revise o texto com sua própria voz, repertório e critérios de originalidade.

## O que o aluno deve reconhecer
**Gancho** = começa uma pergunta dramática que a história promete responder. **Conflito** = alguém quer algo e encontra resistência. **Progressão** = a situação muda por causa das escolhas e consequências. **Reviravolta** = surpresa preparada e coerente. **Retenção** = resultado observado com dados reais, não uma porcentagem prometida pelo prompt.

## Funciona com só o tema?
Sim. Cada um dos dez prompts pode começar só com `{TEMA}`. Quem quiser mais consistência deve continuar no mesmo chat e reutilizar as decisões anteriores. Há diferença entre **o primeiro rascunho automático** e **uma obra bem reescrita**.

## Grátis no celular
Os prompts são textos. Podem ser copiados em versões gratuitas de ferramentas de conversação quando disponíveis, sujeitas a limites e políticas atuais. O aluno não precisa pagar para ler ou editar o arquivo. Produzir a animação com a aparência de um filme 3D é uma etapa diferente e pode exigir recursos adicionais.
