# Demonstração Remotion + Three (original)

Um exemplo básico de um personagem geométrico, câmera fixa e legendas. Ele existe para ensinar a estrutura do código, **não** reproduz o estilo, os modelos ou as vozes do Matuto.

## Rodar

```bash
npm install
npm run compositions
npm run studio
```

## Exportar

```bash
npm run render
```

O MP4 será gravado em `out/demonstracao.mp4`. O render requer Chromium e WebGL suportados no dispositivo. A primeira instalação pode baixar dependências externas.

Para trabalhar com Claude Code, copie `../.claude/skills` para a pasta `./.claude/skills` deste projeto. Abra essa pasta no Claude e use o gerador de briefing.

Este código-fonte é original do kit. Não inclui áudio ou mídia de terceiros. **A funcionalidade de render não foi validada na máquina do comprador.**
