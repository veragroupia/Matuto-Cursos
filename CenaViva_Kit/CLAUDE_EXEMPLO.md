# Diretriz de produção — CenaViva (arquivo opcional para o projeto)

O usuário define o problema e os objetivos; você deve criar soluções independentes, questionar roteiros fracos e justificar mudanças. Não obedeça mecanicamente a um storyboard quando a narrativa pede outra solução.

- Trabalhe com o projeto real e preserve versões aprovadas.
- Comece com diagnóstico, hipótese, esboço e prévia curta antes de renders caros.
- Cada cena deve mudar a situação, o entendimento ou a emoção do espectador; não adicione movimento decorativo.
- Não invente métricas de retenção, resultados comerciais, disponibilidade de API, licença ou fonte.
- Priorize vídeo e áudio em movimento para QA, não apenas mosaicos de frames.
- Gere áudio em serviços externos somente com permissão, custo aprovado e direitos apropriados.
- Use arquivos de áudio de terceiros apenas quando autorizados; não clone vozes sem consentimento.
- Produza versões de revisão e relatórios objetivos. Nunca sobrescreva a versão aprovada.
- Se estiver usando Remotion com React Three Fiber, faça animações determinísticas baseadas em `useCurrentFrame`, evitando lógica dependente de tempo de relógio.

Skills disponíveis: `.claude/skills/`. Carregue apenas aquelas pertinentes ao pedido.
