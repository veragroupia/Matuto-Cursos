# Checklist antes da primeira venda

- [ ] Testei o HTML (preencher, gerar, copiar, baixar .md) no Chrome do computador.
- [ ] Testei em celular que o arquivo abre e que botões funcionam.
- [ ] Instalei as 9 skills em uma pasta de teste e confirmei que o Claude Code as reconhece.
- [ ] Rodei `npm install`, abri o Studio e consegui renderizar `CenaVivaDemo` **no meu computador**.
- [ ] Gravei uma aula real demonstrando instalação, briefing, preview e render. Não dizer que o ZIP inclui aula em vídeo antes de anexá-la ao produto.
- [ ] Mostrei vídeos próprios ou licenciados; não entreguei os assets privados do Matuto.
- [ ] Configurei checkout e recebimento conforme requisitos de cadastro, idade e CPF da plataforma.
- [ ] Defini suporte, reembolso e acesso conforme leis e políticas aplicáveis.
- [ ] Revisei o texto de venda para evitar garantias de viralização ou uso gratuito de serviços pagos.
- [ ] Subi o ZIP para a área de entrega restrita, testei com compra de teste quando disponível.
